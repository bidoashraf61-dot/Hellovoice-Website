# Invented content

Everything on the site that was **written rather than captured**. The brief was to
fill every gap so nothing looks unfinished, then report what was filled — this is that
report.

Three categories:

- **Written** — connective copy, headings, descriptions. Mine. Rewrite freely.
- **⚠ Unverified fact** — a claim, number or name that must be confirmed before launch.
- **Corrected** — captured content whose spelling was fixed.

client logos on file. **The old site published a completely different set** — `1000+
minutes of content`, `98% client retention`, `100+ clients`, `15+ industries` — all
animated up from zero, none sourced. The two sets contradict each other. Pick one.
